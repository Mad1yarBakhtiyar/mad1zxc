# SKAS 2.0 — Adaptive Glass (первый этап)

## Готово
- Адаптивный стеклянный дизайн поверх существующего SKAS.
- Режимы светлый / тёмный / системный, выбор хранится в браузере.
- Чат SKAS AI, запросы проходят через серверную функцию Vercel `api/chat.js`.
- Существующие демо-тесты и роли сохранены.

## Деплой
Загрузите содержимое папки в существующий GitHub репозиторий, затем Vercel пересоберёт сайт. В Vercel Settings → Environment Variables добавьте `OPENAI_API_KEY` (не в GitHub!), затем Redeploy. Для API нужна отдельная оплата OpenAI.

## Важно
База данных **ещё не подключена**. Текущий `api.ts` использует демонстрационные массивы в памяти браузера, поэтому данные теряются при перезагрузке. Демо-авторизация не безопасна для реальных студентов. До публичного запуска нужны Supabase Auth, RLS и серверная проверка оценок. AI-чат сейчас не имеет аутентификации и rate limiting: не публикуйте API-ключ для широкого использования, пока не внедрены эти защиты.
