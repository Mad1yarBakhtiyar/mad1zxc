# SKAS Learning — 140 двуязычных уроков

В разделе **SKAS Learning** доступны 7 дисциплин по 20 уроков (140 всего).
Каждый урок содержит краткую теорию на русском и казахском, пример,
практическое задание и мини-тест. Прогресс хранится в localStorage
этого браузера и не синхронизируется между устройствами.

## Установка
npm ci
npm run build
npm run dev

## Развёртывание
Скопируйте содержимое папки mad1zxc-main в корень GitHub-репозитория,
не загружая саму папку верхнего уровня. Vercel: Vite, npm run build.

## Ограничения
Это учебная демоверсия, а не утверждённая программа Narxoz College.
Материалы являются краткими вводными конспектами, а не полноценными
многостраничными лекциями. Варианты мини-тестов пока однотипные;
для серьёзной проверки знаний потребуются расширенные вопросы.
Данные и прогресс не сохраняются в Supabase.
Вход преподавателей в этой демоверсии не является защищённым.
