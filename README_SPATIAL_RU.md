# SKAS 5.0 · Spatial Glass

Редизайн существующего приложения SKAS на React 19, TypeScript и Tailwind. Новая тема подключена после базовых стилей в main.tsx. Предыдущий вариант SKAS 4.0 сохранён отдельно.

## Запуск готовой версии

Требуется Node.js. В папке SKAS-5.0 выполните:

```sh
node scripts/preview-static.mjs
```

Откройте http://127.0.0.1:5173. Сервер останавливается сочетанием Ctrl+C.

## Что изменено

- Палитра Spatial Glass: #090D1C, #171F38, #6978D9, #B7C4FF и #F0F3FF.
- Плавающая навигация, спокойный световой фон, разные уровни панелей и крупные числовые показатели.
- Общий дизайн входа, Dashboard, Learning, предметов, тестов, результатов, сообщений, настроек и кабинета преподавателя.
- Светлая, тёмная и системная темы; мобильное меню и адаптивная сетка.
- Фокус клавиатуры, reduced-motion, reduced-transparency и уменьшение размытия на мобильных устройствах.

Основной файл оформления: spatial-glass.css. Переменные цветов, глубины, радиусов и геометрии находятся в начале файла.

## Что сохранено

Все исходные аккаунты и коды, роли и ограничения доступа, API, 7 дисциплин, 140 русско-казахских уроков, тесты, автосохранение и существующая модель локальных данных. Ключи хранилищ не изменены, поэтому сохранённые данные в том же браузере и на том же origin продолжают использоваться.

Календарь, XP, новые уведомления и серверная синхронизация оценок не добавлялись. Сообщения и AI по-прежнему требуют исходного сервера; их настройка описана в README_SUPABASE.md.

## Разработка

```sh
npm ci
npm run dev
npm run typecheck
npm test
npm run build
```

В dist включена готовая JavaScript-сборка из пользовательского архива с новой CSS-темой и обновлёнными текстовыми названиями версии. Это позволяет открыть редизайн без скачивания зависимостей. Бизнес-логика сборки не переписана.

## Проверка

В браузере проверены вход студента и преподавателя, Dashboard, каталог курсов и урок, кабинет преподавателя, настройки, переключение светлой/тёмной темы и мобильное меню. При ширине 390 px горизонтального переполнения нет. Синтаксис JavaScript проверен Node.js. Файлы API и учебных материалов сверены с предыдущей версией; логика main.tsx совпадает после исключения импорта темы и названий версии.

Новая сборка Vite, TypeScript и полный набор регрессионных тестов не запускались: зависимости в этой среде не установлены после сетевых ошибок предыдущего этапа. Проверка выполнена на готовой сборке с новой темой. Серверные Supabase-сценарии в локальном предпросмотре не проверены. Production не обновлялся.
