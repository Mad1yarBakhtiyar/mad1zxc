# SKAS 2.0 — Narxoz College Edition

## Что сделано
- Adaptive Glass, красная светящаяся надпись NARXOZ COLLEGE.
- Вход студента по имени и группе.
- Вход преподавателя по одному из пяти выданных кодов.
- Закрепление семи дисциплин за пятью преподавателями.
- Преподаватель видит и редактирует тесты только своих дисциплин.
- Результаты студента и преподавателя фильтруются по владельцу/дисциплинам.
- Создание, изменение, удаление тестов и вопросов.
- Демо-данные сохраняются в localStorage текущего браузера.

## ВАЖНО: только демонстрационная версия
Коды преподавателей находятся в клиентском JavaScript и могут быть извлечены посетителями. localStorage не является защищённой базой данных, данные не синхронизируются между устройствами. Студент без пароля может представиться другим студентом. НЕЛЬЗЯ использовать эту версию для настоящих оценок или публиковать как безопасную систему.

Для продакшена: Supabase Auth, серверная проверка кодов (хеши, rate limit), таблицы профилей, дисциплин, назначений, тестов и попыток, RLS, серверная оценка тестов, журнал действий. После перехода на серверную авторизацию замените все выданные четырёхзначные коды.
