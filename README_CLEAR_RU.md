# SKAS 5.0 — прозрачная тема без фона

Фоновая картинка, затемняющий слой и декоративный фон удалены. Страница имеет прозрачный фон; карточки используют нейтральные полупрозрачные поверхности, тонкие границы и мягкие тени. Текст адаптирован для обычного светлого полотна браузера.

Запуск из папки проекта:

```sh
node scripts/preview-static.mjs
```

Откройте http://127.0.0.1:5173. Если страница уже открыта, обновите её через Ctrl+F5.

Файл clear-glass.css подключён последним и в исходниках, и в готовой версии dist. Он задаёт окончательное оформление поверх сохранённых базовых стилей. Файлы фонового изображения удалены и в архив не включены.

Функции, аккаунты, API и 140 уроков сохранены. В этой правке изменены только стили и оформление страницы. Проверено отсутствие ссылок на фон и совпадение CSS исходников с dist. Повторная сборка Vite и проверка в браузере для этой правки не выполнялись. Готовая версия использует прежнюю JavaScript-сборку с новой CSS-темой.
