# SKAS 4.0 — оформление по референсу Lumina

Сохранены React, TypeScript, Tailwind, все учебные данные и функции исходного приложения. Изменено оформление: фон, прозрачные панели, границы, тени, сетка, размеры карточек, навигация, кольцо прогресса и адаптивные состояния.

## Быстрый запуск без установки пакетов

Из папки проекта выполните:

```sh
node scripts/preview-static.mjs
```

Откройте http://127.0.0.1:5173. Остановка сервера: Ctrl+C.

## Разработка

```sh
npm ci
npm run dev
npm run typecheck
npm test
npm run build
```

Тема находится в `reference-theme.css` и подключена последним импортом CSS в `main.tsx`. Файл содержит переменные геометрии, цвета и адаптивные правила. В `dist/reference-theme.css` находится та же тема для готовой сборки.

## Проверка 29 октября 2026

В браузере проверены вход студента, переход в SKAS Learning, список пяти тестов, главная панель 1179 × 655 и мобильная версия 390 × 844; на мобильном экране нет горизонтального переполнения, меню раскрывается.

Установка зависимостей завершалась сетевыми ошибками соединения с npm. Поэтому новые команды typecheck, test и build не выполнены. Для предпросмотра использована готовая JavaScript-сборка из пользовательского архива с подключённой новой CSS-темой. JavaScript исходного приложения не изменён, добавлен только импорт темы. Повторная сборка из исходников требует доступного npm.

Сообщения и AI сохраняют исходные требования к серверу и ключам; настройки описаны в README_SUPABASE.md и README.md. Никакие новые сервисы к приложению не подключены.
