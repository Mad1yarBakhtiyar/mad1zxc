# Обновление mad1zxc — SKAS Campus

Это архив обновления существующего репозитория **Mad1yarBakhtiyar/mad1zxc**:
https://github.com/Mad1yarBakhtiyar/mad1zxc

## Как применить

1. Распакуйте ZIP во временную папку.
2. Скопируйте **всё содержимое** из неё в корень существующего `mad1zxc`, рядом с его `package.json`, с заменой совпадающих файлов. Папки `components`, `scripts` и `dist` нужно объединить с существующими, сохранив вложенные пути.
3. Сделайте коммит в том же репозитории. Новый репозиторий или новый проект хостинга не нужен.
4. Если текущий хостинг подключён к этой ветке GitHub, он пересоберёт сайт по своему обычному процессу. Для ручной сборки: `npm ci`, затем `npm run build`.

Если загружаете через GitHub: откройте существующий `mad1zxc`, выберите **Add file → Upload files**, перетащите распакованные файлы **и папки**, сохраняя структуру, и сохраните коммит. Сам ZIP загружать в репозиторий вместо распакованных файлов не нужно.

Обновление рассчитано на проверенное дерево репозитория `4143a171904fc2f1a4f4e6c0684621efb2345e0e`. Перед заменой сохраните свои более поздние изменения, если они есть. Файлы и настройки, которых нет в ZIP, остаются в репозитории.

## Состав обновления

- `main.tsx` — новый экран входа, главная, навигация, оформление разделов и иконки.
- `style.css` — новая адаптивная дизайн-система: тёплый фон, графит, оливковый и терракотовый; светлая и тёмная темы.
- `components/glass.tsx` — светлая тема по умолчанию, сохранение выбранной темы и существующей логики компонентов.
- `index.html` — заголовок и цвет интерфейса браузера.
- `dist/index.html`, `dist/assets/*` — готовая production-сборка.
- `scripts/check.mjs`, `scripts/preview-static.mjs` — исходные скрипты из вашего архива по путям, указанным в `package.json`. В проверенной версии GitHub они оказались в корне, из-за чего команды `test` и `preview:static` не находят их по нужному пути.
- `START.cmd` — необязательный локальный просмотр готовой сборки в Windows.

Старые стили `liquid-glass.css`, `spatial-glass.css`, `clear-glass.css` больше не импортируются. Их наличие в репозитории не влияет на новый интерфейс. Новая сборка использует правильный путь `dist/assets/`; старые файлы в `dist/assits` не используются.

## Функции

Сохранены аккаунты и коды входа, роли и права преподавателей, 7 дисциплин, 140 уроков на русском и казахском, прогресс, тестирование, таймер, автосохранение, продолжение теста, оценивание, разбор ответов, история, диаграммы, CSV, редактор тестов, переписка и AI-помощник.

Данные уроков, API, база, настройки подключения, `package.json`, `package-lock.json` и `vercel.json` не заменяются. Переписка и серверный прогресс по-прежнему требуют настроенный Supabase; AI — серверный ключ. Локальный статический просмотр не запускает эти серверные маршруты. См. существующие `.env.example` и `README_SUPABASE.md`.

## Локальный просмотр

После применения обновления откройте `START.cmd` или выполните `node scripts/preview-static.mjs`. Затем откройте http://127.0.0.1:5173. Нужен Node.js; установки зависимостей для готового `dist` не требуется. Для остановки сервера нажмите Ctrl+C. Прогресс локального просмотра хранится в браузере отдельно от опубликованного сайта.
